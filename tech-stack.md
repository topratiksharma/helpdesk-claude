# Tech Stack

## Frontend
- **React** + **TypeScript**
- **React Router** — client-side routing

## Backend
- **Node.js** + **TypeScript**
- **Express** — HTTP server and API

## Database
- **PostgreSQL** — primary data store
- **Prisma** — ORM

## Authentication
- **Database sessions** — sessions stored in PostgreSQL, no JWTs

## AI
- **Claude API (Anthropic)** — ticket classification, summaries, suggested replies

## Email
- **Postmark** or **SendGrid** — inbound parsing (receive emails) and outbound (send replies)

## UI
- **Tailwind CSS** + **shadcn/ui**
